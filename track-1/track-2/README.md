# 📊 Track 2 — Turn Business Data into Strategic Decisions

## Overview

As part of the **Gen AI APAC Edition**, I explored how generative AI and business data can be combined to support strategic decision-making.

## Technologies Used

* Gemini
* BigQuery
* BigQuery MCP Server
* Public datasets

## What I Built

A data-driven coffee shop expansion agent designed to identify suitable locations for a new store by analyzing public datasets and business-related information.

## Workflow

Business Question → Gemini Agent → BigQuery MCP Server → Data Analysis → Strategic Recommendation

## Key Learnings

* Using Gemini for data-driven decision-making
* Exploring MCP-based tool usage
* Working with BigQuery
* Applying public datasets to real-world business problems
