# 🚀 Gen AI APAC Edition

My hands-on learning journey through the **Gen AI APAC Edition**, focused on building and deploying practical AI agents using Google Cloud.

## 🧠 Tracks

### ☕ Track 1 — Build and Deploy a Customer-Facing AI Agent

Built a personalized AI assistant for a coffee shop application using:

* Google Agent Development Kit (ADK)
* Retrieval-Augmented Generation (RAG)
* Gemini
* Cloud Run

**What I built:**
A customer-facing AI assistant that uses RAG to provide personalized coffee recommendations.

**Deployment:**
Deployed on Google Cloud Run.

---

### 📊 Track 2 — Turn Business Data into Strategic Decisions

Built a data-driven coffee shop expansion agent using:

* Gemini
* BigQuery
* BigQuery MCP Server
* Public datasets

**What I built:**
An AI-powered solution that analyzes data to identify cyclist-friendly locations for potential new coffee shops.

**Deployment:**
Built using Google Cloud technologies.

---

### ⚡ Track 3 — Automate Daily Operations with a Productivity Agent

Built a productivity assistant designed to help with everyday business operations.

**What I built:**
An AI assistant for tasks such as checking sales and tracking inventory.

**Technologies:**

* Cloud Run
* AI Agent
* Task automation
